# PhotoSorter downloads

PhotoSorter is a culling, editing, album and studio app for wedding photographers, with a companion phone app.
Website: https://photosorter-nine.vercel.app · Support: support@rapdfly.com

This repository only holds the installers. The source code is private.

**Download the latest version from [Releases](https://github.com/Rapdfly-Developer/photosorter-releases/releases/latest).**

## These are beta builds

* They are **not code-signed yet**, so macOS and Windows will warn you the first time you open them. That's
  expected; the steps below get past it. Signed builds will replace them.
* The phone app's sync needs PhotoSorter Cloud, which isn't open yet. The desktop app works fully on its own.
* Please send problems and ideas from **Settings → Send feedback** in the app, or to support@rapdfly.com.

## Install

### Mac (Apple silicon: M1 or later)
1. Download `PhotoSorter-mac.zip` and double-click it to unzip.
2. Drag **PhotoSorter.app** into your **Applications** folder.
3. Open it. macOS says it can't check the app for malicious software: click **Done** (not "Move to Bin").
4. Open **System Settings → Privacy & Security**, scroll down to "PhotoSorter was blocked…" and click
   **Open Anyway**, then confirm with your password. You only need to do this once.

### Windows 10 / 11 (64-bit)
1. Download `PhotoSorter-windows-setup.exe` and run it.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Follow the installer. PhotoSorter appears in the Start menu.

### Android (beta)
1. Download `PhotoSorter-android.apk` on your phone.
2. Open it and allow your browser to install apps when Android asks.
3. Sync with your computer needs PhotoSorter Cloud, which isn't open yet.

### iPhone
The iPhone app is coming through Apple TestFlight.
